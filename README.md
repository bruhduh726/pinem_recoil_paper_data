# Recoil-Enhanced Temporal Electron Compression — data and code

Data and code that reproduce every data figure of

> T. Brada, C. I. Velasco, and F. J. García de Abajo,
> *Recoil-enhanced temporal electron compression*, Phys. Rev. Research (2026), accepted.
> DOI: [10.1103/z5nb-hq28](https://doi.org/10.1103/z5nb-hq28)

The repository contains

* `pinem_recoil.py` — the numerical core shared by all figures (transfer-matrix propagation of the electron
  sideband amplitudes through the optical field including recoil, free propagation, degree of coherence DOC₁,
  analytical sideband bounds). Depends only on numpy and scipy.
* `figN.ipynb` — one notebook per figure: parameters, computation, saving of the data, and plotting.
* `compute_fig7a_doc_map.py` — standalone script for the computationally expensive DOC₁ map of Fig. 7(a).
* `data/` — the numbers behind every curve and map of the figures as plain-text CSV files, readable in Excel or any
  other program (described in [`data/README.md`](data/README.md)).
* `figures/` — the figures as regenerated by the notebooks (the published versions were additionally
  edited for layout and annotation; the data are the same).

## Running

Python ≥ 3.10 with numpy (≥ 2.0), scipy and matplotlib; Jupyter to open the notebooks.

With [uv](https://docs.astral.sh/uv/) (Linux, macOS, Windows):

```
uv sync
uv run jupyter lab
```

or with pip in any virtual environment:

```
pip install -r requirements.txt
jupyter lab
```

Open the notebooks from the repository folder (Jupyter's default), so that `import pinem_recoil` and the relative
`data/` paths resolve; no paths need to be edited on any operating system.

Each notebook loads its data from `data/` if the files exist and otherwise recomputes them. Set `RECOMPUTE = True`
in the first code cell to recompute from scratch. The map of Fig. 7(a) is recomputed only with
`RECOMPUTE_MAP = True` in `fig7.ipynb`, or directly with

```
python compute_fig7a_doc_map.py --workers 8
```

(see the script's docstring for options; the map in `data/fig7/` was computed with 64 processes in about 8 minutes).

## Model and conventions

All quantities are dimensionless as in the paper: ζ = ωz/v, θ = ωt, coupling g = evE₀/ħω², recoil parameter
a = 2mₑv²γ³/ħω (a → ∞: no recoil), Talbot distance ζ_T = 2πa. The wave function is expanded in energy sidebands,
φ(ζ, θ) = Σ_ℓ φ_ℓ(ζ) e^{−iℓθ}, and P_ℓ = |φ_ℓ|². The interaction with a field of uniform amplitude and linearly varying
phase is solved by the transfer-matrix method of the paper's appendix (`pinem_recoil.step_matrix`); the field-phase
step per propagation step `d_phi = −d_zeta · v_ph/v` sets the phase mismatch (`d_phi = −d_zeta`: phase matching for ℓ = 0).
Free propagation after the interaction is evaluated in the frame co-moving with the electron, where only the recoil
phase e^{−2πiℓ² ζ_free/ζ_T} acts. See the docstring of `pinem_recoil.py` for details.
